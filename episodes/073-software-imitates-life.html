Biology has a lot to teach us about successful complex systems. As with other disciplines, we can adapt biological concepts to help us create better software — both in code and in how we work. In this episode, your hosts talk about how we can apply concepts from cells, genetics, and evolution to practical concepts like team creation, code communication patterns, and architecture. You may never code up your own genetic algorithm, but we think you'll find the concepts interesting and useful.
