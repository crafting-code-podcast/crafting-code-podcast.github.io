In prior episodes we've mentioned that although code can be art of itself, we usually focus on the value provided by the functionality from executing the code. But crafting code in a way that creates said value in a sustainable way is difficult, and how you go about it constitutes an art form of its own. In this episode, Allan and Dave discuss the difference between code as art and the art of coding. We talk about why this distinction matters both in the codebase and also to the coders.
